# Fonts

These are the Latin subsets of open-source fonts from Google Fonts, saved here so every planner
works offline. Each one is licensed under the [SIL Open Font License 1.1](https://openfontlicense.org),
which allows bundling them in software like this. Copyright stays with each font's designers.

Anton, Archivo Black, Caveat, Chakra Petch, Cinzel, Cormorant Garamond, DM Mono,
DM Serif Display, EB Garamond, Fraunces, IBM Plex Sans, Karla, Manrope, Nunito Sans, Permanent Marker,
Pixelify Sans, Press Start 2P, Quicksand, Shrikhand, Space Grotesk,
UnifrakturMaguntia, VT323.

To download them again: `npm run fonts`.
